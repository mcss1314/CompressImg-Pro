# CompressImg-Pro

CompressImg-Pro 是一款专为 Sigil 开发的高性能 EPUB 电子书图像优化插件。本插件集成了多种图像处理引擎与精准的全书引用解析算法，支持批量图像格式转换、质量压缩、智能尺寸缩放、PNG 颜色量化、隐私元数据擦除，以及基于正文阅读顺序的智能批量重命名功能。<br/>
GUI 界面采用现代化的折叠卡片与可交互预览设计，配合多线程并发处理与双阶段安全回滚机制，为电子书排版与体积瘦身提供高效、安全的解决方案。

## 🌟 核心特性
- **多格式兼容与交互式预览**：全面支持读取并处理 **BMP、JPG/JPEG、PNG、WEBP** 等主流图像格式。内置交互式预览面板，双击即可查看图片分辨率、文件体积与像素格式；支持在处理前对选中图片执行 **90° / 180° / 270°** 旋转操作。
- **全方位格式转换与质量调优**：支持在 **JPEG、PNG、WEBP** 目标格式之间自由转换。提供**无损压缩**（0–9 级可调压缩率）与**质量有损压缩**（5–100% 质量系数）双重转换策略。针对 JPEG 重新编码优化了色彩空间转换（精准处理 CMYK 印刷色彩与 Transparency Alpha 通道），避免色彩失真或变黑。
- **智能尺寸缩放与重采样**：支持**百分比缩放**（1–500%）或**按指定宽度 / 高度**等比例缩放。动态重采样算法：系统根据缩放比例自动在 `BOX`（大比例缩小）、`BICUBIC` 与 `LANCZOS`（高质量平滑）之间切换，兼顾处理效率与渲染画质。
- **高级 8 位量化与无损压缩**：集成 `imagequant` 算法库（自动降级兼容），支持将 32 位 PNG 图像量化压缩为高品质 8 位调色板 PNG，大幅削减 PNG 图片体积。提供针对 JPEG/WEBP 的高级无损压缩优化（优化 Huffman 表与子采样）。
- **按阅读顺序智能批量重命名**：深度解析 EPUB 内所有的 HTML、XHTML、CSS 及 SVG 文本。按照图片在正文中的实际出现顺序（调用链）自动对图片重新命名（如 `p001.jpg`、`p002.png`）；若同一图片被多处调用，将自动合成多页标识。
- **封面保护机制**：精准识别 OPF 元数据中的 Cover 声明与属性，自动跳过封面图片的重命名与盲目修改。
- **全书引用同步重构**：自动将全书 HTML 中的 `<img>`、`<source>`、`srcset` 以及 CSS 中的 `url(...)`、`@import` 引用同步更新为新文件名与相对路径。
- **隐私保护与元数据擦除**：一键清理图像内置的 EXIF 属性、相机拍摄参数、ICC 配置文件及敏感 Header 信息，进一步减小体积并保护隐私。
- **并发加速与双阶段原子回滚**：底层基于 `ThreadPoolExecutor` 构建多线程任务池，自动匹配 CPU 核心数进行并发渲染。采用**双阶段提交架构**：所有变更先在临时目录与内存中预演并验证，确认无误后再一次性提交。若中途发生任何异常，系统将启动**完整原子回滚**（还原图像二进制、HTML 文本及 OPF 元数据），确保 EPUB 文件绝不损坏。

## 📦 环境依赖

插件内置了环境感知与自愈提示功能。运行本插件需要以下第三方库的支持：

- `Pillow` (>= 8.0.0，核心图像处理引擎，**必需**)
- `imagequant` (可选，用于 PNG 高级 8 位颜色量化压缩)

💡 **依赖缺失自动修复**：若 Sigil 环境中缺少 `Pillow` 库，插件启动时会自动弹出修复窗口，并为您生成一键复制的 `pip install --target` 命令行脚本，帮助您将依赖直接装入插件目录。

## 🚀 安装指南

1. 打开 Sigil 软件，在顶部菜单栏选择 `插件` → `编辑插件`。
2. 点击 `添加插件`，选择压缩包文件进行安装。
3. 安装成功后，插件将被放置于 Sigil 官方插件目录中：<br/>
　Windows: `%APPDATA%\sigil-ebook\sigil\plugins\CompressImg-Pro`<br/>
　macOS: `~/Library/Application Support/sigil-ebook/sigil/plugins/CompressImg-Pro`
4. 重新启动 Sigil，即可在顶部菜单栏 `插件` 下找到并启动 CompressImg-Pro。

## ⚙️ 功能面板说明

启动插件后，主界面分为左右两大区域：

- **左侧**：图片管理与筛选
  - **格式筛选器**：勾选/取消勾选 BMP、JPEG、PNG、WEBP 快速过滤列表中显示的图像。
  - **快捷选择**：提供「全选」、「反选」以及按 `<Ctrl+A>` 快捷键全选。
  - **旋转控制**：选中单张或多张图片后，可执行顺时针 90°、逆时针 90° 或重置旋转。
  - **双击预览**：双击列表中的任意图像即可打开预览弹窗，查看图片的分辨率、体积与当前旋转状态。

- **右侧**：参数配置面板（折叠卡片）
  - **格式转化**：启用后可选择目标格式（JPEG / PNG / WEBP），并切换无损模式或质量压缩模式。
  - **质量压缩与缩放**：微调 JPEG / WEBP 的输出质量参数（5–100），或配置按百分比、指定宽度/高度缩放。
  - **高级压缩**：开启 PNG 8 位量化压缩（需 `imagequant` 支持）及 JPEG/WEBP 无损压缩增强。
  - **隐私与清理**：
    - **清除图片元数据**：剥离 EXIF / ICC 等信息。
    - **按 HTML 调用顺序批量重命名**：勾选后将自动重构全书图片文件名及正文中的引用路径。

注：配置参数会自动持久化保存至本地 `.sigil_compress_plugin_prefs.json` 文件中，下次启动时自动加载。

## 💡 使用流程

1. 在 Sigil 中打开需要压缩或优化的 EPUB 电子书。
2. 在顶部菜单栏启动 **CompressImg-Pro** 插件。
3. **选择目标图片**：在左侧列表中勾选需要处理的图片（可通过筛选栏过滤，或双击核对图片）。
4. **配置优化策略**：在右侧面板勾选所需的处理项（如格式转换、质量调整、尺寸缩放或批量重命名）。
5. **执行处理**：点击右下角 `🚀 执行处理` 按钮。
6. 插件将在后台开启多线程处理，界面实时显示当前进度。
7. **结果确认**：处理完成后，插件会自动将优化后的图像写入电子书并更新相关引用。若处理过程中出现任何异常，系统会弹出错误日志汇总窗口并自动安全回滚。
